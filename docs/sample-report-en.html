3. DMARC in monitor-only mode (p=none)

What we found

4. Accepts obsolete protocols (TLSv1, TLSv1.1)

What we found
The server accepted a connection using TLSv1, TLSv1.1.
Why it matters

Disable TLS 1.0 and 1.1 on the server/CDN; keep TLS 1.2 and 1.3.
